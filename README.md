# Hearthstone Card Browser

## Project Description
The Hearthstone Card Browser is a web application that allows users to browse cards from Blizzard's Hearthstone game by expansion, view card details, and save favorite cards to a cloud database. Users can dynamically select expansions, load all cards, and add them to a favorites list which persists via Supabase. This project demonstrates asynchronous data fetching, REST API usage, and cloud database interaction.

### Target Browsers
- Desktop: Chrome, Firefox, Edge, Safari (latest versions)
- Mobile: Responsive design supported on iOS Safari and Android Chrome
- Note: For full functionality, a modern browser that supports ES Modules and Fetch API is required.
