Hearthstone Card Project – Details

Project Overview

This project allows users to browse Hearthstone cards by expansion, view card details, and save favorite cards to a database. It demonstrates the use of external APIs, JavaScript, and a Supabase backend to store user favorites.

How the Project Works

  1. Card Search: Users select an expansion from the dropdown. Cards are dynamically loaded from the Hearthstone API using fetch().
  2. Favorites: Each card has a "⭐ Add to Favorites" button. Clicking it saves the card to a Supabase database table. Users can view all saved favorites on the Favorites page.
  3. Details Page: Provides instructions and explains how the project works. It also describes the APIs used and functionality.

APIs and Technologies Used

  • Hearthstone API: Provides card data including images, names, and expansions.
  • Supabase: Used for storing and retrieving favorite cards. This demonstrates CRUD functionality on a cloud database.
  • Fetch API: Used to retrieve data asynchronously from both external APIs and the database.
  • JavaScript: Handles DOM manipulation, event listeners, and dynamic content rendering.
  • CSS Grid & Styling: Responsive layout for cards and favorites.

How to Use the Application

  1. Go to the Card Search page.
  2. Select an expansion from the dropdown and click "Load Cards".
  3. Browse through the cards. Click "⭐ Add to Favorites" to save a card.
  4. Go to the Favorites page to view all saved cards.

Notes

  • The application requires an internet connection to fetch card data from the Hearthstone API.
  • Favorites are stored in Supabase and persist across sessions.
  • For full functionality, make sure your API keys and Supabase keys are correctly configured.
